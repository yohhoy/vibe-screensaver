# 作品の HTML を書くとき

コードを書く・直す前に、DEVELOPMENT.md の「方針」節を読む。新作や構成の変更なら「ファイルの構成」節（節の順番の表）も読む。仕上げは「作品を追加・変更したとき」節に沿う。見た目を変えないリファクタリングなら「見た目を変えないリファクタリング」節を読む。

要点:

- 1 作品 = HTML 1 ファイル。ビルド・npm は使わない。共通の処理は common.js・common.css に置く。
- スクリプトは `// ---- 設定 ----` などの節に分け、節の順番を揃える。
- 調整できる値は「設定」節に定数で置き、名前で分からない定数には意味・単位・範囲をコメントで書く。
- 時間で進む位相は JS で 0〜2π に収めてからシェーダーに渡す。
- 描く回数を抑えるときは jellyfish.html と同じ `nextDraw` の書き方にする。
- MSAA にするのはシーンを描く描画先だけにする。
