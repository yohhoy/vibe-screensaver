## 作品ごとの注意

- waterfall と diamond は倍率が高いと `MSAA` を切る（`MSAA_OFF_PIXEL_RATIO`）。waterfall は画素が増える Retina の方が軽い。
- pipes はパイプが伸びるにつれて重くなる（動かなくなった部品は材質ごとに結合する。描画命令は 15 秒の間に最大 267 まで増える）。表の値は途中の中央値。
- lavalamp は、塊が少ない状態の値になる。
- sandpicture は、砂が少ない状態の値になる。
- infcastle は、固定の乱数の 15 秒の間（最初の数部屋）の値になる。部屋の中身は乱数で変わるので、ほかの部屋では値が変わりうる。廊下・隠し部屋・重力の回転は測っていない。
- teapot で重いのは Ray Tracing・Path Tracing・Displacement Mapping・Subsurface Scattering の 4 つで、負荷を比べるときはこの 4 つを見れば足りる。teapot は `MAX_PIXEL_RATIO` が 1.5 なので、Retina の描画の解像度は 1920×1248 になる（ほかの作品は 2560×1664）。
- bubbles の Meadow（FHD）は基準負荷が 6.6ms（クロックは約 1000MHz）で、最速まで上がっていない。ほかの行は 5.3〜5.6ms。
- orrery は 2026-11-23 に Chrome 157.0.8103.79 で測った（ほかの作品は上の「測った条件」の日付と版）。基準負荷が 9.0〜10.2ms（クロックは約 630〜810MHz）で、最速まで上がっていない。GPU タイマーがコマ全体より大きく、実時間とは対応しない（MSAA を切ったときも、ぼかしの段数を変えたときも、GPU タイマーだけが段数に対して一様でない動きをした）ので、変更前後の比べ方はコマ全体で判断する。`MAX_PIXEL_RATIO` が 1.5 なので、Retina の描画の解像度は 1920×1248 になる。Candle の描画命令のうち約 110 回は、点光源の影（影を落とす部品を 6 方向に描く）による。MSAA は使わず、TAA で縁をならす。
- marbles は 2026-11-23 に Chrome 157.0.8103.79 で測った（ほかの作品は上の「測った条件」の日付と版）。シーンは積み木の材質（Wood・Stone・Metal）。FHD の Wood・Stone は基準負荷が 6.0〜6.1ms（クロックは約 1100MHz）で、最速まで上がっていない。`MAX_PIXEL_RATIO` が 1.5 なので、Retina の描画の解像度は 1920×1248 になる。
- pixelcity・flume は 2026-11-26 に Chrome 158.0.8127.38 で測った（ほかの作品は上の「測った条件」の日付と版）。GPU の負荷はほとんど無い（GPU タイマーは FHD で約 0.1〜0.3ms）ので、GPU の表には載せず、JS の時間を載せる。変更の前後は、[performance.md](performance.md) の「CPU で描く作品」の手順で比べる。pixelcity は、最初の時代の値になる（時代は時間とともに進み、後の時代ほど重い）。flume の描くドット数は画面の解像度によらないので、FHD と Retina の値はほぼ同じになる。
- hexnet は 2026-11-28 に Chrome 158.0.8127.38 で測った（ほかの作品は上の「測った条件」の日付と版）。基準負荷が 12.0〜13.7ms（クロックは約 510〜570MHz）で、最速まで上がっていない。表の値は、起動から 15 秒（最初の島が育っている途中）の値になる。群島ができあがったあと（リンク障害の起きている間を含む）の GPU タイマーも、同じ程度だった。
