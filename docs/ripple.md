# ripple.html — 雨の水面

水面すれすれの低い視点から、雨の降る広い水面を眺める。雨粒の落ちた所から波紋が広がり、水面に映った空や明かりを揺らす。

## カメラ

- 水面の近くから少し見下ろしたまま、左右を見回す（周期 90 秒）。

## 雨と波紋

- 雨粒は画面内の水面にランダムに落ち、着水した点から波紋が広がる。
- 波紋は数本の輪の束で、広がるにつれて束がゆるみ、弱くなって消える。
- 重なった波紋は干渉し合う（傾きを足し合わせる）。
- 起動直後から波紋がある状態にするため、降っていた分の波紋を最初に置く。
- 雨筋は、着水する雨粒だけを風で少し斜めにした線で描く。

## 水面

- 空を映す。斜めから見るほど強く映り（フレネル）、波紋とうねりで映り込みが揺れる。
- 遠くは地平線の霞に溶ける。

## 景色

3 種類。起動時はランダムに選ぶ。

- **夜の湖面** — 星空と黄色っぽい月。月の光の道が波紋で揺れる。遠くを遊覧船が 1 隻横切り、窓と電飾の灯りが水面に光の帯として映る。
- **街あかり** — 対岸に並ぶビル群（`CITY_SCALE` 倍に大きくした手前の列と、霞んだ奥の列）。空は寒色の夜空で、地平線の近くだけ街明かりが黄色くにじむ。窓は寒色、岸辺の街灯は黄色で、街灯は水面に縦に伸びた光の帯として映る。手前の列の背の高いビルだけ、屋上の赤い航空障害灯が明滅する。
- **霧雨の朝** — 明るい曇り空と濃い霧。遠くに霧で霞んだ山並み（2 重）と針葉樹の森が薄く見える。

## シーン切替

暗転している間に、上の順で次の景色へ切り替える。

## 強度

強度は雨の強さ。範囲は 1〜24 粒/秒、最初は 8 で、1 回の操作で 1.25 倍ずつ変える。

## 隠し要素（景色ごとの出来事）

景色ごとに、ときどき（30〜180 秒おき、平均 60 秒ほどに 1 回）起こるランダムな出来事が 1 種類だけある。

- **夜の湖面: 流れ星** — 空を流れ、水面にも映る。
- **街あかり: UFO**
  - 形: ドームと平たいつば、つばの下を回るピンクのライト。ドームとつばは影で形だけで見分け、底だけがピンクに光って下の空ににじみ、つばの下の縁を照らす。空の色に少し霞ませる。
  - 動き: 画面の外から上下に揺れながら現れ、遠くの空で 2〜3 秒止まったあと、ライトを速く回して斜め上へ飛び去り、小さくなりながら消える。
  - 映り込み: 水面にも映り、底の光は街灯と同じく縦に伸びた光の帯になる。ビルの後ろを通るときは隠れる。
- **霧雨の朝: 跳ねる魚** — 飛び出しと着水で水しぶき（真上に上がる水柱と、輪の形に外へ広がる粒）と大きな波紋が立つ。落ちたしぶきも小さな波紋を立てる。

**C** キーで、いまの景色の出来事をすぐに起こせる（操作ガイドには表示しない）。出来事が起きている間は何もしない。

## 描き方

- 波紋は、雨の落ちる範囲を覆うテクスチャに 1 つずつリングとして描き（傾きを加算）、水面はそれを読んで映り込みを揺らす。波紋の数が増えても負荷はほとんど変わらない。同時に描くのは 128 個までで、超えたら古いものから消す。
- 遠くで輪が画素より細かくなる所は、ミップマップと異方性フィルタでならしてちらつきを防ぐ。
- うねりや航空障害灯の明滅の位相は JS（倍精度）で 0〜2π に収めてからシェーダーに渡す（[DEVELOPMENT.md](../DEVELOPMENT.md) の「方針」参照）。

## 景色の定義

景色は `SCENES` 配列に 1 つずつ書く。色はすべて画面に出る値（0〜1）。

| 項目 | 意味 |
|---|---|
| `name` | 操作ガイドに表示する名前 |
| `zenith` / `horizon` | 天頂 / 地平線の空の色 |
| `light` | 月・太陽 `{ dir: [方位, 高度], color, size, glow }`（rad。方位は正面が 0、右が正）。無ければ `null` |
| `stars` / `city` / `land` / `boat` | 星空 / 地平線の街並みと街灯 / 遠くの山と森 / 遊覧船を出すか（省略すると出さない） |
| `event` | ときどき起こるランダムな出来事（1 つの景色に 1 種類）。`'meteor'`: 流れ星、`'ufo'`: UFO、`'fish'`: 跳ねる魚。省略すると無し。種類を増やすときは `EVENTS` に、間隔と、始める・進める・片付ける処理を書く |
| `water` | 水そのものの色 |
| `f0` | 真上から見たときの反射率 |
| `fog` | 遠くを霞ませる濃さ |
| `rain` | 雨筋の色と不透明度 `[r, g, b, a]` |
