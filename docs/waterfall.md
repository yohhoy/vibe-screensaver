# waterfall.html — 滝

## 仕様

深い森の大きな滝を、滝壺の手前の低い位置から見上げる。カメラは滝の方を向いたまま、左右・上下・前後にゆっくり漂う。縦長の画面では、滝の幅が収まるよう縦の画角を広げる。

- 崖
  - 横に長い 1 枚の格子で、崖の面から崖の上の台地まで続ける。滝の近くほど格子を細かくする。
  - 崖の形は滝を囲む弧で、両側ほど手前に迫る。縦の割れ目と地層で区切った岩の塊を、列ごと・段ごとに前後にずらす。足もとには崩れた斜面が張り出す（滝の近くには無い）。
  - 滝の裏はえぐれている。滝口のまわりは凹凸を抑え、水の帯が崖に埋もれないようにする。
  - 色は頂点ごとに付ける。岩の明暗のまだら、岩肌を伝う水の縦のしみ、上向きの面と足もとの苔。滝の裏と水際は濡れて暗い。
- 木と岩
  - 足もとの広葉樹は、葉の束を描いたテクスチャ（canvas に描く）を貼った板を重ねて作る。透明な所は `alphaTest` で捨てる。
    - 大きさの違うふくらみをでこぼこに並べて板を散らすが、法線はふくらみごとではなく樹冠の中心からの向きにする（ふくらみごとに陰影を付けると、玉の集まりに見える）。
    - 幹と枝はほとんど葉に隠れるので簡略にする。幹は細い角すい、枝は 3 本だけにする。
    - 幹と枝も葉の板と同じ材質で描く（描画の回数を増やさないため）。テクスチャの右上の角を白く不透明に塗り、幹と枝の頂点はみなそこを指す。葉の板はそれ以外の範囲（`LEAF_UV_SIZE`）だけを使う。
    - 板は表（外向き）だけ描く。裏も描くと法線が反転して黒い塊に見える。内側の板は暗くして、向こうの透けを減らす。
    - 三角形の葉を積むより三角形が大幅に少ない。形の種類は 3。
  - 足もとの針葉樹は垂れ下がる枝の三角形を積んで作る。法線は面の向きではなく、枝の外向きにする。画面の両端を縁取るので、三角形を多く使う。
  - 崖の上の木は遠くて葉や枝の 1 本ずつは見えないので、木を丸ごと描いたテクスチャの板を 1 本につき 1 枚、カメラに向けて立てる。
    - 葉の板を重ねて作ると、離れた板が円盤のように浮いて見える。枝の三角形を積むと、枝の間が透けて枯れ木に見える。
    - 広葉樹は樹冠だけを板にする（2 × 2 の区画に 4 種類）。中央のかたまりと、それに必ず重なる外側のふくらみを描くので、ひとつながりで、ふちはでこぼこになる。幹は別の細い角すいで、板は幹より少し手前に出す（幹が葉の上に透けないように）。
    - 針葉樹は木全体を板にする（4 × 2 の区画に 8 種類）。枝のスカートを下の段から塗り重ね、枝の先ほど明るくする。
    - 隅ごとに法線を外へ開いて、1 枚の板でも丸みのある陰影にする。板はカメラの基準の位置に向けて固定する（カメラの漂う幅より遠いので、向きを追わなくても目立たない）。
  - 滝口の真上は川なので、少し奥まで木を置かない。
  - 岩は球をランダムな平面で切り落として角ばらせる。滝壺の岸に沿って並べる。
  - 滝口の岩は縁に埋め込み、水の帯をその脇へよける。水が岩の左右に分かれて流れ、すぐ下で合流する。岩の下に濡れた崖が短くのぞくので、岩が崖とつながって見える。滝口のまっすぐな線を崩す役目もある。
- 滝
  - 細い水の帯を何本も重ねる（`StreamShader`）。帯は滝口から放物線を描いて水面まで落ちる。
  - 筋の模様のテクスチャ（下が明るく上へ薄れる細長い水塊）を 2 枚重ねて流す。テクスチャの縦の座標を「落ちた秒数」にしているので、下へ行くほど模様が伸びて速くなる。流れる位相は JS で 0〜1 に収めてから渡す。
  - 滝口はなめらかな水の色で、落ちるにつれて白く泡立つ。帯ごとに白さを変えて縦の柱の模様にし、滝の端ほど薄くして岩を透かす。
  - 帯のまわりに、速さの向きに伸ばした線で水滴を落とす。
- 滝壺
  - 水面は `Reflector` で描いた映り込みを波で揺らす。揺らすのはほぼ縦の向きだけにする（横にも揺らすと、滝の映り込みが規則的なジグザグに見える）。斜めから見るほど強く映す（フレネル）。
  - 滝の落ちる線からの距離で、波と泡の模様を放射状に外へ流す。泡は滝に近いほど多く、外へ行くほどまばらになって消える。
  - しぶきは滝の落ちる線から跳ね上がる粒。霧は大きなふわふわした粒で、立ちのぼるものと、滝の足もとで低くわき立つものがある。足もとの霧で滝と水面の境をぼかす。霧は奥行きの判定をしない（岩や水面に切られて輪郭が出ないように）。
  - 映り込みの描画先では、水面の下に入った光線が岩の裏を抜けて低い空に届く。波で読む位置がずれると岸の下でこの色を拾うので、崖より低い空（実際の景色には見えない）は水の色で塗る。
  - 映り込みは小さい描画先に描くので、そのときだけ粒の大きさも同じ割合に縮める。
- GPU の負荷を抑えるための工夫（水の表現は削らず、それ以外を簡略にする）
  - マルチサンプルにするのはシーンを描く描画先だけで、2 倍にとどめる。ブルームと合成の描画先までマルチサンプルにすると、全画面の処理がとても重くなる。
  - 解像度の倍率が高い画面（`MSAA_OFF_PIXEL_RATIO` 以上）では MSAA を切る。画素が細かくてぎざぎざが目立たず、負荷も大きく減る。倍率の低い画面では残す。崖の上の木の板は切り抜きなので、もともと MSAA が効かない。
  - ブルームは解像度を半分にして描く。効果がほとんど無い昼の景色では描かない。
  - 水以外の材質は `MeshLambertMaterial` にし、凹凸（`bumpMap`）は使わない。
  - 映り込みには、水面に映る範囲にほとんど入らないもの（崖の上の木）と、映っても見分けられない細かいもの（しぶき、水滴、星、虹）を描かない（`MAIN_ONLY_LAYER`）。
  - 木は画面に入る範囲（`inView`）と、崖に隠れない奥行き（`RIM_TREE_DEPTH`）にだけ置く。
- 景色は 3 種類。起動時はランダムに選ぶ。シーン切替（Space・左右スワイプ）では、暗転している間に下の順で次の景色へ切り替える。
  - **新緑の昼** — 青空と白い雲。霧に虹がかかる
    - 虹は太陽と反対の向きを中心にした円で、カメラから見た向きで決まる。赤・緑・青の山を重ねて色を作り、少し白っぽくする
    - 霧のある所（低い所、滝の近く）にだけ見せる。濃さと横の広がりは水量（霧の量）と滝の幅に合わせる
    - 色を足すだけだと白い滝の上で色が消えるので、下の景色を少し薄めてから足す（`RAINBOW_TINT`）。暗い岩の上では淡く光り、白い滝の上では淡い色として見える
  - **夕暮れ** — 紫からオレンジへの空。低い太陽が横から照らし、片側の崖だけが赤く染まる
  - **月夜** — 星空と月。滝だけが青白く浮かび上がる
- 強度（↑↓・上下スワイプ）で水量を変える。
  - 水の帯は中央に近い順に並べ、先頭から水量に比例した本数を描く。水量が増えると滝の幅が広がる。順番を少し乱して、端へは細い筋から増えていくようにする。
  - 水滴・しぶき・霧の数も水量に比例する。

## 景色の定義

景色は `SCENES` 配列に 1 つずつ書く。色はすべて画面に出る値（0〜1）。

| 項目 | 意味 |
|---|---|
| `name` | HUD に表示する名前 |
| `zenith` / `horizon` | 天頂 / 低い空の色 |
| `fog` | 遠くを霞ませる色と濃さ `[r, g, b, 濃さ]` |
| `cloud` | 雲の色と濃さ `[r, g, b, 濃さ]` |
| `stars` | 星空を出すか |
| `ambient` | 空の光 `{ sky, ground, intensity }` |
| `light` | 太陽・月の光 `{ color, intensity, dir }`。虹の向きにも使う |
| `disc` | 空に見える月 `{ dir, color, size }`（`size` は半径 rad）。無ければ `null` |
| `lit` / `shade` / `glass` | 滝の白い所 / 影の所 / 滝口のなめらかな水の色 |
| `mist` | 霧の色と不透明度 `[r, g, b, a]` |
| `spray` | しぶきと水滴の色 |
| `deep` / `foam` | 滝壺の水そのものの色 / 泡の色 |
| `rainbow` | 虹の濃さ（0 で無し） |
| `bloom` | ブルーム `{ strength, threshold }`（`strength` が 0 なら描かない） |
| `exposure` | 全体の明るさ |
