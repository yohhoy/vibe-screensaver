# drone.html — ナイトドローン

## 仕様

ワイヤーフレームと点群で描いた夜の街を、紙飛行機の形をしたドローンが飛び続ける。カメラはドローンの後ろから追いかける。

- コースは高低差のある 3 種類で、どれも決まった形の周回コース。起動時はランダムに選ぶ。
  - **Downtown** — 大通りを低空で抜け、超高層ビルの谷間を急上昇して急降下
  - **Harbor** — 水面すれすれの海沿いから吊り橋の主塔をくぐり、街の上へ
  - **Tower** — 展望台くらいの高さから鉄骨の電波塔の全体を正面に見て近づき、塔のまわりをおおまわりに周回しながら降下。低空で抜けたあと U ターンして、再び塔へ向かう
- シーン切替（Space・左右スワイプ）では、暗転している間に上の順で次のコースへ切り替える。
- コース上には一定間隔で輪が並ぶ。
  - 輪は時間とともに虹色に少しずつ移ろう。隣の輪とは色相を少しずつずらす。
  - ドローンがくぐる直前に、破裂するように広がりながら暗く消える。半周先まで行くと元に戻る。
- 街はコースごとに決まったシードで生成されるので、毎回同じ街になる。コースに近いビルは、コースより低く抑える。
- 夜景の要素
  - ビルの輪郭とフロアの線（高いところほど明るい）
  - ランダムに灯る窓、街灯、道路を流れる車のライト
  - 高いビルの屋上で点滅する航空障害灯
  - 街の外に並ぶ遠くのビル群（淡い輪郭と窓。高さはその街のビルに合わせる）
  - 星空、海のきらめき（Harbor）
- ドローンは下りで加速、上りで減速し、曲がるときはバンクする。翼端には航法灯（左が赤、右が緑）があり、縁のぼやけた帯状の光跡を引く。

## コースの定義

コースは `COURSES` 配列に 1 つずつ書く。

| 項目 | 意味 |
|---|---|
| `name` | HUD に表示する名前 |
| `seed` | 街を生成する乱数のシード |
| `hue` / `ringHue` | 街の色相 / 輪の虹色の始まりの色相 |
| `points` | 閉じたコースの制御点 `[x, 高さ, z]` の配列 |
| `rings` | 輪を置くコース上の位置（0〜1）の配列。省略すると `RING_INTERVAL` ごと |
| `city.density` / `city.maxHeight` | ビルの密度 / 最も高いビルの高さ |
| `city.center` / `city.spread` | ビルが高くなる中心 `[x, z]` / 高さが落ちていく広がり |
| `city.waterZ` | （任意）これより奥を海にする |
| `city.bridge` | （任意）吊り橋 |
| `city.landmark` | （任意）電波塔 |
