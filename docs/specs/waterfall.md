# waterfall.html — 滝

深い森の大きな滝を、滝壺の手前の低い位置から見上げる。白い水が流れ落ち、滝壺から霧が立ちのぼる。

## カメラ

- 滝の方を向いたまま、左右・上下・前後にゆっくり漂う。
- 縦長の画面では、滝の幅が収まるよう縦の画角を広げる。

## 崖

- 横に長い 1 枚の格子で、崖の面から崖の上の台地まで続ける。滝の近くほど格子を細かくする。
- 崖の形は滝を囲む弧で、両側ほど手前に迫る。縦の割れ目と地層で区切った岩の塊を、列ごと・段ごとに前後にずらす。足もとには崩れた斜面が張り出す（滝の近くには無い）。
- 段のずれは所々だけ強くする。どこも同じだと、段の影が崖の端から端まで黒い線で続き、板を積んだように見える。上の段を必ず奥へ引いて棚にするやり方は、規則的な縞に見える。
- 面の陰影は三角形ごとに付ける（`flatShading`）。なめらかにすると、段のずれを弱めたときに硬く見える所が無くなり、崖がぼけて見える。
- 滝の裏はえぐれている。滝口のまわりは凹凸を抑え、水の帯が崖に埋もれないようにする。
- 滝口の線は中央がくぼみ、両端へ上がる。細かな高低差も付けて、まっすぐな線に見えないようにする。
- 色は頂点ごとに付ける。岩の明暗のまだら、岩肌を伝う水の縦のしみ、上向きの面と足もとの苔。地層は段の影だけに頼らず、明るさの違う帯でも見せ、広い範囲で岩の色みを暖色へ寄せる。滝の裏と水際は濡れて暗い。崖の上の台地は草の色にする。

## ツタ

崖の上端からだけ垂らす。中腹からは垂らさず、滝のすぐ脇にも置かない（滝と崖の境を見せる）。左右の数は揃えず、位置はランダムにする。

- 筋を垂らした束をテクスチャ（canvas に描く）に描き、1 束を 1 枚の板にする。葉の板を並べるより三角形が大幅に少なく、丸い粒の列にも見えない。
- 板は崖の面に沿って縦に分割し、幅の中でいちばん手前の位置に合わせて、岩に埋もれないようにする。上端は幅の中でいちばん低い崖の高さに合わせて、空へはみ出さないようにする。
- 筋ごとに始まる高さをずらす。揃えると、束の上端が四角く切れて見える。
- 筋は太めに描き、`alphaTest` のしきい値を葉より下げる。細いと、遠くで透明として捨てられて消える。
- 法線は崖の弧の向きにする。カメラへ向けると、影の側の崖でも光って見える。

## 崖の上の木

崖の上の木は遠くて葉や枝の 1 本ずつは見えないので、木を丸ごと描いたテクスチャの板を 1 本につき 1 枚、カメラに向けて立てる。

- 葉の板を重ねて作ると、離れた板が円盤のように浮いて見える。枝の三角形を積むと、枝の間が透けて枯れ木に見える。
- 広葉樹は樹冠だけを板にする（2 × 2 の区画に 4 種類）。中央のかたまりと、それに必ず重なる外側のふくらみを描くので、ひとつながりで、ふちはでこぼこになる。幹は別の細い角すいで、板は幹より少し手前に出す（幹が葉の上に透けないように）。
- 針葉樹は木全体を板にする（4 × 2 の区画に 8 種類）。枝のスカートを下の段から塗り重ね、枝の先ほど明るくする。
- 隅ごとに法線を外へ開いて、1 枚の板でも丸みのある陰影にする。板はカメラの基準の位置に向けて固定する（カメラの漂う幅より遠いので、向きを追わなくても目立たない）。
- 滝口の真上は川なので、少し奥まで木を置かない。奥ほど背を高くして稜線を作る。

## 足もとの草木

足もとに背の高い木は置かない（岩と水が隠れ、崖の大きさも伝わりにくくなる）。代わりに低い草木で崖の足もとを縁取る。滝の近くはまとまりごとに間をあけて岩と水を見せ、画面の端は間をあけずに、少し大きく生やす。増やしすぎると崖に迫って見えるので、斜面の上端までは生やさない。

低木は、葉の束を描いたテクスチャ（canvas に描く）を貼った板を重ねて作る。透明な所は `alphaTest` で捨てる。形の種類は 2。

- 葉のふくらみは中央のかたまりに必ず重ねる。離れたふくらみは、宙に浮いた塊に見える。
- 法線はふくらみごとではなく中心からの向きにし、上へ寄せる。ふくらみごとに陰影を付けると玉の集まりに見え、下の葉が光をまったく受けないと黒い塊に見える。
- テクスチャの葉は小さな房に分けて置く。一様に散らすと、板 1 枚が丸い円盤に見える。
- 板は表（外向き）だけ描く。裏も描くと法線が反転して黒い塊に見える。内側の板は暗くして、向こうの透けを減らす。

シダは、根もとから放射状に葉を出す。葉は軸の左右に細い小葉を並べ、弧を描いて垂れる。テクスチャは使わず三角形で描く。

倒木は左右に 1 本ずつ、決まった位置に置く。根もとは斜面に、先は水に沈めて、切り口を見せない。区切りごとに苔の色を変え、折れた枝を 2 本残す。幹の法線はなめらかにする（面ごとにすると角材に見える）。

低木、シダ、滝壺の岩は、1 つずつ明るさと色みを少し変える。

## 岩

- 球をランダムな平面で切り落として角ばらせる。滝壺の岸に沿って並べる。
- 滝口の岩は縁に埋め込み、水の帯をその脇へよける。水が岩の左右に分かれて流れ、すぐ下で合流する。岩の下に濡れた崖が短くのぞくので、岩が崖とつながって見える。滝口のまっすぐな線を崩す役目もある。

## 滝

- 細い水の帯を何本も重ねる（`StreamShader`）。帯は滝口から放物線を描いて水面まで落ちる。
- 滝全体は下へ行くほど広がり、帯は隣の帯と揃って左右に寄る。まっすぐ落とすと、幅が一定の長方形に見える。
- 帯は風でゆっくり左右に揺れる。揺れは滝壺の近くほど大きい。
- 筋の模様のテクスチャ（下が明るく上へ薄れる細長い水塊）を 2 枚重ねて流す。テクスチャの縦の座標を「落ちた秒数」にしているので、下へ行くほど模様が伸びて速くなる。流れる位相は JS で 0〜1 に収めてから渡す。
- 滝口はなめらかな水の色で、落ちるにつれて白く泡立つ。隣り合う帯の白さを揃えて太い縦の柱の模様にし、滝の端ほど薄くして岩を透かす。
- 帯のまわりに、速さの向きに伸ばした線で水滴を落とす。

## 滝壺

- 水面は `Reflector` で描いた映り込みを波で揺らす。揺らすのはほぼ縦の向きだけにする（横にも揺らすと、滝の映り込みが規則的なジグザグに見える）。斜めから見るほど強く映す（フレネル）。
- 滝の落ちる線からの距離で、波と泡の模様を放射状に外へ流す。泡は滝に近いほど多く、外へ行くほどまばらになって消える。カメラが低いので、白い範囲が狭いと細い線につぶれて見える。そのため水面に広く取る。
- 泡には外へ広がる白波の輪も重ねる。模様で位相をずらし、切れ切れの白波に見せる。
- しぶきは滝の落ちる線から跳ね上がる粒。
- 滝の落ちる線の上のあちこちで、水が砕けて塊で噴き上がる（水量 1 倍のとき、0.1〜1.2 秒おき、平均 0.35 秒ほどに 1 回）。1 回は短く、同じ所から水の線と水煙を一緒に出す。水の線は落ちる水と同じ重力で動かす（軽い粒で描くと、舞う雪に見える）。
- 霧は大きなふわふわした粒で、立ちのぼるものと、滝の足もとで低くわき立つものがある。足もとの霧は滝の幅より外まで広げ、滝と水面の境をぼかす。霧は奥行きの判定をしない（岩や水面に切られて輪郭が出ないように）。
- 起動直後から霧が立ちこめている状態にするため、10 秒ぶん先へ進めてから描き始める。

## 景色

3 種類。起動時はランダムに選ぶ。

- **Daylight** — 青空と白い雲。霧に虹がかかる。
  - 虹は太陽と反対の向きを中心にした円で、カメラから見た向きで決まる。赤・緑・青の山を重ねて色を作り、少し白っぽくする。
  - 霧のある所（低い所、滝の近く）にだけ見せる。濃さと横の広がりは水量（霧の量）と滝の幅に合わせる。
  - 色を足すだけだと白い滝の上で色が消えるので、下の景色を少し薄めてから足す（`RAINBOW_TINT`）。暗い岩の上では淡く光り、白い滝の上では淡い色として見える。
- **Sunset** — 紫からオレンジへの空。低い太陽が右手前から照らし、左の崖がオレンジに染まる。右の影の崖は空の光で紫に寄せる。影まで赤茶にすると、全体が濁って片側だけ染まって見えない。左右の明暗は極端にせず、影の側も岩の形が読める程度に照らす。
  - 夕日の光の筋が、滝口の上の左から崖の上部へ斜めに差し込む。アクセントなので、範囲は崖の上部に絞り、淡くする（広く覆うと、崖に霞がかかって景色の印象が変わる）。
  - 筋を描いたテクスチャ（canvas に描く）の半透明の板を重ね、色を足す。奥行きの判定はしない。濃さをゆっくり変えて、光を揺らがせる。
- **Midnight** — 月夜。滝が青白く浮かび上がる。崖は黒く沈まないよう、空の光で形が読める程度に照らす。草木の緑は暗く青寄りにする（そのままだと鮮やかな緑が夜の中で浮く）。月のまわりの光は、円盤とは別の青寄りの色にする（円盤と同じ暖色だと、夜空の上で濁る）。
  - 滝壺のまわりの岸と水面の上に蛍が飛ぶ。決まった場所のまわりを漂い、ゆっくり明滅する。足もとの霧の外から一定の範囲だけに飛ばし、霧の中やカメラのそばには置かない。奥の蛍ほど暗くして、遠近感を出す。

## シーン切替

暗転している間に、上の順で次の景色へ切り替える。

## 強度

強度は水量。範囲は 0.13〜2 倍、最初は 1 倍で、1 回の操作で 1.25 倍ずつ変える。

- 水の帯は中央に近い順に並べ、先頭から水量に比例した本数を描く。水量が増えると滝の幅が広がる。順番を少し乱して、端へは細い筋から増えていくようにする。中央は乱さない。乱すと、水量が少ないときに帯が散らばって薄く透けて見える。
- 水滴・しぶき・霧の数と、水が噴き上がる回数も水量に比例する。
- 蛍の範囲は霧の幅に合わせて動く。水量が増えると外へ移り、減ると滝に寄る。飛び移って見えないよう、ゆっくり追いつかせる。

水量が 1 倍より少ないときは、泡が広がる距離、滝の近くの波、霧の濃さと大きさ、しぶきと噴き上がる水の速さも小さくする。細い滝に対して足もとが大きく見えないようにする。滝の幅が変わらなくても、水の勢いの差が分かる。

## 描き方

- 映り込みの描画先では、水面の下に入った光線が岩の裏を抜けて低い空に届く。波で読む位置がずれると岸の下でこの色を拾うので、崖より低い空（実際の景色には見えない）は水の色で塗る。
- 映り込みは小さい描画先に描くので、そのときだけ粒の大きさも同じ割合に縮める。

GPU の負荷を抑えるための工夫は次のとおり（水の表現は削らず、それ以外を簡略にする）。

- MSAA を掛けるのはシーンを描く描画先だけで、2 倍にとどめる。ブルームと合成の描画先にも掛けると、全画面の処理がとても重くなる。
- 解像度の倍率が高い画面（`MSAA_OFF_PIXEL_RATIO` 以上）では MSAA を切る。画素が細かくてぎざぎざが目立たず、負荷も大きく減る。倍率の低い画面では残す。崖の上の木の板は切り抜きなので、もともと MSAA が効かない。
- ブルームは解像度を半分にして描く。効果がほとんど無い昼の景色では描かない。
- 崖、岩、木、草木、ツタの材質は `MeshLambertMaterial` にし、凹凸（`bumpMap`）は使わない。
- 映り込みには、分割を 1/4 に粗くした崖を描く。崖は三角形の大半を占め、映り込みは小さくて波で揺れるので、粗くても見分けられない。
- 映り込みには、水面に映る範囲にほとんど入らないもの（崖の上の木、ツタ、光の筋）と、映っても見分けられない細かいもの（しぶき、水滴、虹、シダ、蛍）を描かない（`MAIN_ONLY_LAYER`）。
- 崖の上の木と足もとの草木は画面に入る範囲（`inView`）にだけ置く。崖の上の木は、崖に隠れない奥行き（`RIM_TREE_DEPTH`）にも絞る。
- スマホなどでは、水滴と霧の粒、噴き上がる水の線と水煙、崖の分割、木と草木とツタの数、葉の板の数、映り込みの解像度を減らす。

## 景色の定義

景色は `SCENES` 配列に 1 つずつ書く。色は、断りが無ければ画面に出る値（0〜1）。

| 項目 | 意味 |
|---|---|
| `name` | 操作ガイドに表示する名前 |
| `zenith` / `horizon` | 天頂 / 低い空の色 |
| `fog` | 遠くを霞ませる色と濃さ `[r, g, b, 濃さ]` |
| `cloud` | 雲の色と濃さ `[r, g, b, 濃さ]` |
| `ambient` | 空の光 `{ sky, ground, intensity }` |
| `light` | 太陽・月の光 `{ color, intensity, dir }`。虹の向きにも使う |
| `disc` | 空に見える月 `{ dir, color, size, glow }`（`size` は半径 rad、`glow` はまわりの光の色。`color` と `glow` は線形の値で、`color` は 1 を超えてよい）。無ければ `null` |
| `foliage` | 木、草木、倒木、ツタの色に掛ける色 |
| `fireflies` | 蛍を出すか |
| `shafts` | 光の筋を出すか |
| `lit` / `shade` / `glass` | 滝の白い所 / 影の所 / 滝口のなめらかな水の色 |
| `mist` | 霧の色と不透明度 `[r, g, b, a]` |
| `spray` | しぶきと水滴の色 |
| `deep` / `foam` | 滝壺の水そのものの色 / 泡の色 |
| `rainbow` | 虹の濃さ（0 で無し） |
| `bloom` | ブルーム `{ strength, threshold }`（`strength` が 0 なら描かない） |
| `exposure` | 全体の明るさ |
