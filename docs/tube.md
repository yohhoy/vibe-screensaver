# tube.html — チューブトンネル

## 仕様

曲がりくねった輪っか状のコースを、チューブの中から眺めながら飛び続ける。

- コースは起動するたびにランダムに作られ、途切れずに周回する。
- シーン切替（Space・左右スワイプ）では、暗転している間に新しいコースと配色に切り替える。
- 壁はネオン調のグリッドで、光のにじみ（ブルーム）が付いている。
  - 8 本ごとの明るいリング
  - 奥へ流れる光のパルス
  - ところどころでまたたくパネル
  - 遠くほど暗く溶けるフォグ
- 進行方向（画面中心）から外側へ流れる弱い放射ブラーで、スピード感を出す。速度を上げるほど強くなる。
- カメラはゆっくり回転し、少し揺れながら進む。
- 配色はシアン、マゼンタ、グリーン、レインボー、アンバーの 5 種類。起動時はランダムに選ぶ。

## 隠し要素

ときどき、壁のグリッドの 1 マスがハッチになり、Claude Code のマスコットが跳び出してくる。

1. 進行方向の少し先で、壁の 1 マスが点滅する。
2. ハッチが開き、マスコットがトンネル中央に向かって放物線を描いてジャンプする。跳んでいる間はばんざいして、カメラの方を向く。
3. 同じ穴に戻ると、ハッチが閉じる。

- 平均 10 秒に 1 回のペースで、不規則に現れる。間隔は最長 60 秒。
- **C** キーを押すと、すぐに呼び出せる（操作ガイドには表示しない）。
- 速度を変えても、カメラが着く前に着地するようにタイミングを合わせる。
